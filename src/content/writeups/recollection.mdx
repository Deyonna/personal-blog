We will analyze the memory dump of the asset provided. Throughout the walkthrough both Volatility 2 and 3 are used depending on the case.

### Task 4

**Question:** The attacker copied the obfuscated command to use it as an alias for a PowerShell cmdlet. What is the cmdlet name?

If we run the command `(gv '*MDR*').naMe[3,11,2]-joIN''` in PowerShell we get back the string `iex`.

After a quick google search we can see that `iex` is the alias for the `Invoke-Expression` cmdlet which according to Microsoft:

> Invoke-Expression cmdlet evaluates or runs a specified string as a command and returns the results of the expression or command.

**Answer:** `Invoke-Expression`

### Task 8

**Question:** What was the Host Name of the machine?

There are two ways to obtain the hostname of the machine. Initially I went through the normal way but then I noticed there is a much simpler way to accomplish this, unique to this particular challenge.

#### Normal Way

In order to find the hostname of a machine we have to examine the registry. Specifically the key where this info is found is normally present at the location `ControlSet001\Control\ComputerName\ComputerName`

First we need to determine the virtual address of the registry hive that contains the above information which is under `\REGISTRY\MACHINE\SYSTEM`:

```bash
vol.py --profile=Win7SP1x64 -f recollection.bin hivelist
```

And we get the following results:

```
$vol.py --profile=Win7SP1x64 -f recollection.bin hivelist
```

### Task 10

**Question:** In the `"\Device\HarddiskVolume2\Users\user\AppData\Local\Microsoft\Edge"` folder there were some sub-folders where there was a file named `passwords.txt`. What was the full file location/path?

We use the `filescan` plugin to locate `passwords.txt` within the memory image. `filescan` walks memory for `FILE_OBJECT` structures and lists every file Windows had a handle open to at the time of capture, along with the physical offset of each one and its full path.

```bash
vol.py -f recollection.bin --profile=Win7SP1x64 filescan | grep -i passwords.txt
```

**Answer:** `\Device\HarddiskVolume2\Users\user\AppData\Local\Microsoft\Edge\User Data\ZxcvbnData\3.0.0.0\passwords.txt`

### Task 11

**Question:** A malicious executable file was executed using command. The executable EXE file's name was the hash value of itself. What was the hash value?

The `consoles` output captured back in Task 5 shows the attacker running:

```
.\b0ad704122d9cffddd57ec92991a1e99fc1ac02d5b4d8fd31720978c02635cb1.exe
```

Since the question tells us the filename is the hash, we just strip the `.exe` extension.

**Answer:** `b0ad704122d9cffddd57ec92991a1e99fc1ac02d5b4d8fd31720978c02635cb1`

### Task 12

**Question:** Following the previous question, what is the Imphash of the malicious file you found above?

Imphash (import hash) is computed from a PE file's import table, not something Volatility reports directly so we need the actual binary. We locate its physical offset with `filescan`, then extract it with `dumpfiles`:

```bash
vol.py -f recollection.bin --profile=Win7SP1x64 filescan | grep -i b0ad704122d9cffddd57ec92991a1e99fc1ac02d5b4d8fd31720978c02635cb1.exe

vol.py -f recollection.bin --profile=Win7SP1x64 dumpfiles -n --dump-dir=./ -Q <offset from filescan above>
```

Once dumped, the Imphash can be read straight off a VirusTotal report for that file, or computed locally with a PE-parsing tool such as pefile/peframe.

**Answer:** `d3b592cd9481e4f053b5362e22d61595`

### Task 13

**Question:** Following the previous question, tell us the date in UTC format when the malicious file was created?

This is the PE header's `TimeDateStamp` (compile time). Using the same dumped file from Task 12, this is visible on the VirusTotal "Details" tab as the file's creation/compile time, or via a local PE-parsing tool. Note this field can be forged by the malware creators.

**Answer:** `2022-06-22 11:49:04`

### Task 14

**Question:** What was the local IP address of the machine?

We use the `netscan` plugin, which lists network connections and sockets present in memory at capture time, showing both local and foreign endpoints for each one.

```bash
vol.py -f recollection.bin --profile=Win7SP1x64 netscan
```

**Answer:** `192.168.0.104`

### Task 15

**Question:** There were multiple PowerShell processes, where one process was a child process. Which process was its parent process?

We use `pstree` to view the process list as a parent/child hierarchy (indentation shows the nesting) — this makes it straightforward to spot which of the several `powershell.exe` entries is nested under another process, and read off that parent's name/PID.

```bash
vol.py -f recollection.bin --profile=Win7SP1x64 pstree
```

**Answer:** `cmd.exe`

### Task 16

**Question:** Attacker might have used an email address to login a social media. Can you tell us the email address?

We search the raw memory image directly for UTF-16LE encoded strings (`-el`) containing "mail". This is a way to surface email addresses that were typed into a login form or otherwise sitting in process memory, even if no file on disk references them.

```bash
strings -el recollection.bin | grep -i mail | more
```

**Answer:** `mafia_code1337@gmail.com`

### Task 17

**Question:** Using MS Edge browser, the victim searched about a SIEM solution. What is the SIEM solution's name?

We locate the browser's `History.dat` (or equivalent Edge history artifact) the same way as Task 12, find its offset with `filescan`, extract it with `dumpfiles` and then open it to review search/browsing history for the SIEM product name.

```bash
vol.py -f recollection.bin --profile=Win7SP1x64 filescan | grep -i history

vol.py -f recollection.bin --profile=Win7SP1x64 dumpfiles -n --dump-dir=lol -Q <offset from filescan above>

open file.None.<offset>.History.dat
```

**Answer:** `Wazuh`

### Task 18

**Question:** The victim user downloaded an exe file. The file's name was mimicking a legitimate binary from Microsoft with a typo (i.e. legitimate binary is `powershell.exe` and attacker named a malware as `powershall.exe`). Tell us the file name with the file extension?

The directory listing in Task 5 shows the Downloads folder contents, including:

```
-a---        12/19/2022   3:00 PM     309248 csrsss.exe
```

`csrss.exe` (Client/Server Runtime Subsystem) is a legitimate, well-known Windows binary but `csrsss.exe` has an extra "s".

**Answer:** `csrsss.exe`
