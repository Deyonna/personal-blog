# 0xdeyonna

Personal blog: CTF / HackTheBox writeups, DFIR knowledge pages and tools.
Built with [Astro](https://astro.build) and deployed to GitHub Pages at
https://deyonna.github.io/personal-blog/ on every push to `main`.

## Running locally

```bash
npm install
npm run dev      # http://localhost:4321/personal-blog/
npm run build    # production build + search index, into dist/
```

## Writing

- [Writing writeups](docs/writing-writeups.md): adding a writeup, locking
  it while the box is active, unlocking it when it retires, and choosing tags.
